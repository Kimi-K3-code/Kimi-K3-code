# 🛠️ Antigravity Conversation Renamer

أداة سريعة وسهلة لتغيير وتعديل أسماء محادثات **Antigravity IDE** في ثوانٍ مع الأرشفة الذكية التلقائية! 🚀

---

## ⚡ طريقة التشغيل المباشرة (الزر Run ▶️)

1. افتح ملف `rename_conversation.py` في الـ IDE.
2. اضغط على زر **▶️ Run Python File** (فوق على اليمين).
3. هيشتغل السكريبت تفاعلياً في التيرمينال:
   - هيسألك عن الاسم القديم (قبل).
   - لو لقى المحادثة هيظهرلك باللون **الأخضر 🟢**.
   - دخل الاسم الجديد (بعد).
   - هيتم التعديل والتوثيق فوراً باللون **الأزرق 🔵**.

---

## 📁 نظام الأرشيف والسجلات الذكي (history_logs/)

تم تفعيل نظام **الدمج الشامل (النظام الهجين)**:

### 1️⃣ الفهرس العام الشامل: `CHATS_LOG.md`
- جدول مركزي مرتب تلقائياً بأحدث المحادثات وتعديلاتها بتوقيت مصر 🇪🇬 (`13-09-2026 | 01:45 PM`).
- يحتوي على:
  - الاسم الحالي
  - الاسم السابق (قبل)
  - الـ ID الكامل
  - رابط مباشر لملف المحادثة التفصيلي
  - تاريخ ووقت آخر تعديل

### 2️⃣ الملفات الفردية لكل محادثة:
- كل محادثة ليها ملف مستقل يحمل اسمها والـ ID الخاص بيها (مثال: `IDE زيزو Version__37dd563d.md`).
- يحتوي الملف على سجل تاريخي كامل بكل التغييرات التي طرأت على اسمها منذ إنشائها.

---
